# 2026-09-01 — Drafting Table v0.2.0 release notes

First interactive iPad canvas iteration.

## Usable in this build

- Real Drafting Table compass app icon and light launch appearance;
- Warm paper canvas with visible Pages, Layers, and tool rails;
- Apple Pencil drawing and finger drawing when the system Pencil-only preference is off;
- Pressure-aware thick graphite strokes with lighter predicted tails;
- Single-point dots, Undo, and Clear;
- Visible diagnostics overlay.

## Still foundations/placeholders

- Page and layer controls are not connected to the portable document model;
- Documents are not persisted across launches;
- Eraser, shade, vector tools, snapping, selection, pan/zoom, and export are not implemented;
- The sparse Metal tile backend is not yet connected to the immediate canvas renderer.

`DraftingTable.ipa` is an unsigned arm64 device build intended for SideStore or another sideloading signer.
