# 2026-09-03 — v0.9.1 prerelease

## Visible color tool

The picker existed but was buried in Settings. The rail now opens with a
color swatch tile (top of DRAW) that shows the live brush color with
contrast-aware ink and presents the HSV picker directly. Picks share one
`applyBrushColor` path with Settings, so engine, autosave, prefs, and the
swatch stay in sync from either entry point.

## Smooth joins on tight curves

v0.9.0 removed beading by cutting intermediate fans, which exposed wedge
gaps where dense quads turn sharply. The renderer now stamps a small
six-slice round join at every interior point using that point's exact
local radius: overlapping stamps at the true local width form a smooth
envelope (dab-stamper style) with no gaps and no beads. Ends keep full
caps; taps still render as dots. Vertex cost stays inside the existing
per-frame budget.

## Live grid snapping for shape tools

The `snap:` status chip is now functional: with snap on and the grid
visible, line/rectangle/ellipse/circle samples round to grid intersections
in `CanvasView.makeSample`. Brush and eraser never snap. Angle snap and
vector-geometry snapping remain M5 work; pixel grid remains M11.
