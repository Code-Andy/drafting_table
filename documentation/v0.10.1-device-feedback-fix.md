# Drafting Table 0.10.1 device-feedback fix

Version 0.10.0 compiled and launched but failed its essential product test on
a physical iPad: Pencil input did not produce committed ink, and the retained
0.9-style chrome still clipped and crowded text. Version 0.10.1 treats that
build as failed and addresses both reports.

## Dead-pen root cause

`DTEngineBridge` reserved a raster transaction when a stroke began. When the
stroke ended, `dt_drainStrokeQueueLocked` returned immediately whenever any
transaction was in flight. The in-flight transaction was the stroke's own
transaction, so `enqueueEndStroke` was never sent to Metal. No generation
could commit, checkpoint, save, or enter undo.

The queue now blocks only the submission of a different, not-yet-submitted
stroke. It still sends the end command for the already-submitted front stroke.

Two device-dependent suppressors were removed as well:

- Pencil contact begins ink even when the first force sample is zero or still
  estimated. Pressure continues to control brush radius; it no longer decides
  whether the stroke exists.
- The new renderer resets inherited 0.9 transform defaults once, preventing
  an old transform from mapping all Pencil samples outside the clipped page.

## Runtime regression gate

The simulator smoke test no longer checks launch survival alone. It now:

1. launches a fresh install with an explicit renderer-self-test environment;
2. submits five real samples through the public `DTEngineBridge` Pencil path;
3. waits for the renderer commit and manifest-last package publication;
4. opens the resulting `.dtile` file; and
5. fails unless at least one persisted alpha byte is nonzero.

The accepted run produced 425 nonzero-alpha pixels and passed the simulator
launch check. Persistent stage breadcrumbs are printed if a future run fails
before manifest publication.

## UI correction

- The one-page navigator, oversized legacy top palette, and overflowing bottom
  status-chip strip start hidden.
- A 64-point left dock exposes Brush, Eraser, Undo, Redo, Layers, Reset, and
  the compact menu.
- The two-layer inspector is a 240-point panel anchored to the safe-area right
  edge instead of stacking every rail on the left.
- Layer rows are 44 points tall with larger visibility, type, opacity, and
  handle regions.
- The menu is wider but adapts to compact width; titles may use two lines and
  truncate deliberately rather than wrapping unpredictably.
- Unsupported activation-threshold, shape, export, import, and bucket controls
  are removed from the active preview UI. Brush color/size/opacity/hardness
  remain available in Drawing Settings.

## Verification

- Portable C++: seven of seven suites pass.
- Xcode arm64 device build and unsigned IPA packaging pass.
- Provenance checks pass.
- Simulator process survives launch under AddressSanitizer.
- Synthetic bridge-to-Metal-to-package stroke persists 425 nonzero-alpha
  pixels.

Physical Apple Pencil latency, hover, prediction appearance, and final panel
spacing still require the next iPad installation because the simulator cannot
reproduce Pencil hardware behavior.
