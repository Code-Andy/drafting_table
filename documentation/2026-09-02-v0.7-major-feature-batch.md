# Drafting Table v0.7.0 — major feature batch

Development date: 2026-09-02 (America/Toronto).

This release is the first broad iPad workspace expansion after the retained
page/layer foundation. It deliberately combines document operations, drawing
style, technical shape tools, Pencil affordances, and interchange so the app
can be tested as a coherent notebook rather than one isolated feature at a
time.

## Drawing and technical tools

- Brush and Eraser remain available.
- Line, Rectangle, and Ellipse are now selectable retained tools.
- Shape tools use the first and last real Pencil samples and ignore predicted
  tails when committing.
- Every retained entry snapshots color, opacity, size, hardness, and tool so
  later settings changes do not alter old marks.
- A system color well and 0–100% hardness control live in Settings.
- The immediate Metal renderer uses stored RGBA, pressure-aware width, soft
  fringe/core rendering, and premultiplied blending.
- A persistent document-space drafting grid can be toggled from Settings or the
  document menu and follows pan, zoom, and rotation.

These shape entries are real persistent outline tools, but they are not yet
editable vector-layer objects. Vector selection, snapping, angle constraints,
SDF parity, and rasterize/merge remain future work.

## Pages and layers

- Pages and layers can be duplicated.
- Pages and layers can move up/down while retaining active-object identity.
- Duplicate names are made unique and duplicate redo stacks are cleared.
- Page cards display generated drawing thumbnails.
- Thumbnail caching avoids re-exporting every page after every Pencil stroke.
- Existing visibility, opacity, active-layer Undo/Redo, Clear Layer, rename,
  add, delete, and minimum-structure guards remain intact.

## Pencil and input

- Apple Pencil hover displays a non-marking brush-size preview.
- Pencil double-tap toggles Brush/Eraser; invoking it from a shape tool returns
  to Brush first.
- Pencil Pro squeeze toggles once at its terminal phase rather than repeatedly
  across phase updates.
- Diagnostics now include active tool and hover state.
- Activation/lift-off pressure tuning remains hidden in Settings and retains
  its release hysteresis.

## Files, export, and interchange

- Current page exports to PNG using a deterministic Core Graphics renderer.
- All pages export to a multi-page PDF without mutating active selection.
- `.drafttable` is registered as a Files document type.
- Open validates a selected archive transactionally before replacing the live
  session.
- Save Copy exports an atomic `.drafttable` archive through the system picker.
- Share sheets and document pickers are configured for iPad presentation.

The `.drafttable` file is currently one bounded DTAR archive. It is not yet a
directory package with lazy sparse tile loading, crash journals, or Android
tile-folder migration.

## Archive v3

DTAR v3 adds current and per-entry color/hardness plus the expanded tool enum.
Version 1 flat-stroke and version 2 page/layer archives migrate with graphite
color and 80% hardness defaults. Validation remains bounded, little-endian,
trailing-data strict, and transactional.

Portable tests cover:

- style clamping and per-entry snapshots;
- Line/Rectangle/Ellipse v3 round trips;
- genuine v1 and v2 migration fixtures;
- malformed future-version/truncated/trailing rejection;
- duplicate independence and move ordering;
- arbitrary-page rendering snapshots.

## Known boundaries

- The visible canvas still uses immediate retained geometry rather than the
  sparse Metal tile compositor.
- Eraser still paints paper color rather than destination-out alpha.
- Hardness is a visible two-pass approximation, not Android tile coverage
  parity.
- Shape tools are not editable vectors and do not snap.
- Export uses the current canvas dimensions; page-size presets are pending.
- Image import, fill, shade, lasso/selection, copy/paste, rasterize/merge,
  vector-layer types, document browser, and Android package migration remain.
- Real-iPad acceptance is still required for hover, Pencil squeeze, shape feel,
  thumbnail cost, picker behavior, and exported-file fidelity.
