# 2026-09-01 — Drafting Table v0.4.0 release notes

Retained drawing-session and core tools milestone.

## New in this build

- Brush and Eraser tool buttons with visible selected state;
- Per-stroke brush size and opacity retained when settings change later;
- Settings sheet for Pen activation, Brush size (1–40 pt), and Brush opacity (5–100%);
- Pen activation is no longer exposed in the primary bottom tool rail;
- Undo and Redo stacks with enabled/disabled UI state;
- Catmull-Rom curve subdivision before pressure-aware thick Metal geometry;
- Round joins/caps retained throughout the smoothed path;
- Versioned, bounded little-endian stroke archive with malformed-data rejection;
- Atomic autosave in Application Support after committed drawing changes;
- Automatic restore on launch and final save when the scene enters background;
- Corrupt archives are quarantined instead of repeatedly blocking launch;
- Current tool and drawing settings persist in UserDefaults;
- Committed `FEATURE_ROADMAP.md` covering the remaining M1–M12 dependency path.

## Current implementation boundaries

- Eraser replays warm-paper geometry in stroke order. It is useful on the current single paper canvas but is not yet a true destination-out sparse-tile eraser.
- Autosave stores retained strokes for this milestone. Files-compatible multi-document/page/layer packages and Android tile migration remain future milestones.
- Pages and Layers rails remain clearly marked placeholders.
- Semi-transparent stroke overlap is still rendered by the immediate retained renderer; uniform-alpha coverage will move to the Metal tile path.

`DraftingTable.ipa` is an unsigned arm64 device build intended for SideStore or another sideloading signer.
