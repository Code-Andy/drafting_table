# 2026-09-01 — Drafting Table v0.5.0 release notes

Canvas coordinate-space and gesture milestone.

## New in this build

- All new Pencil/direct-touch samples are converted from view coordinates to stable document coordinates before entering C++;
- Metal applies the matching document-to-view scale, rotation, and translation;
- Simultaneous two-finger pan, pinch, and rotation;
- Pinch and rotation preserve the document point under the gesture centroid;
- Direct-finger drawing is cancelled when a two-finger gesture takes ownership, preventing accidental committed marks;
- Active Pencil strokes block gesture start so one stroke never changes coordinate maps midway;
- Scale is clamped to 0.1x–8x and rotation is normalized;
- Coherent per-frame renderer transform snapshots prevent half-updated pinch/rotation frames;
- View transform persists across launches without writing UserDefaults on every gesture frame;
- Reset View button restores identity pan/zoom/rotation.

## Current boundaries

- The current paper is still an infinite warm surface; visible page bounds and fit-to-page behavior arrive with the real pages/layers milestone.
- Finger drawing still follows the system Pencil-only preference.
- Brush/Eraser, Undo/Redo, Settings, and retained-stroke autosave from v0.4 remain available.
- Sparse Metal tile rendering, vector tools, snapping, selections, and Files document packages remain future milestones.

`DraftingTable.ipa` is an unsigned arm64 device build intended for SideStore or another sideloading signer.
