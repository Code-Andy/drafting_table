# Drafting Table v0.6.0 — retained pages and layers

Released 2026-09-02 from commit `57b11c5`.

## What is new

- Real retained page and layer ownership instead of placeholder rail items.
- Select, add, rename, and delete pages and layers from dynamic rails.
- Guards prevent deleting the document's final page or a page's final layer.
- Layer visibility and opacity controls.
- Brush/Eraser strokes, Undo, Redo, and Clear Layer target the active layer.
- Visible layers on the active page render bottom-up.
- `DTAR` archive v2 persists names, active indices, visibility, opacity, styles,
  and samples.
- Existing v1 flat-stroke autosaves migrate into `Page 1 / Ink`.
- Portable tests cover v1 migration, v2 round trip, deletion guards, malformed
  data, and transactional failure behavior.

## Existing behavior retained

- Pressure-aware Apple Pencil input with smoothed curved strokes.
- Software Pencil activation/lift-off threshold under Settings.
- Brush and Eraser size/opacity, Undo/Redo, autosave, and launch restore.
- Two-finger pan, pinch, and rotation with persistent document/view transform.
- Reset View, real app icon, paper canvas, and unsigned SideStore-compatible IPA.

## Known boundaries

This release uses retained stroke pages/layers and the immediate Metal stroke
renderer. It does not yet include page thumbnails, page/layer reorder,
raster/vector layer types, sparse tile composition, true destination-out
erasing, Files document packages, multi-document browsing, import/export,
vectors/snapping, or selections.
