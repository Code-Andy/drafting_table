# 2026-09-04 — v0.9.8 Release: Compact Page Previews, Dynamic Subtool Menus, Popover Color Tool & Built-in In-App Menu Window

## Overview

Version **0.9.8** (build **17**) delivers:
1. **Compact Page Previews & Fonts**: Reduced page card thumbnails (52x34), 9.5pt page titles, and compact 72pt page rail width.
2. **Top-Left Subtool Menus with Dynamic Page Rail Avoidance**: Added dedicated `brushSubToolBar` (size, opacity, hardness sliders); both Bucket and Brush menus dynamically anchor to the right of the Page rail when opened (`pagesRail.trailingAnchor + 12`) or tool rail when closed.
3. **Popover Color Selector**: Tapping the Color tool button opens the HSV palette immediately as an iPad popover pointing directly to the swatch tool.
4. **Built-in In-App Menu Window (No Scroll)**: Replaced modal action sheets with a custom `AppMenuWindowView` non-scrolling palette window styled in Drafting Table paper aesthetics with integrated Export & Share subview.

---

## 1. Compact Page Previews & Smaller Typography

- **Thumbnail Sizing**: Reduced thumbnail generation target size from `96x60` to `52x34`, eliminating excessive scaling and producing crisp previews.
- **Card Sizing**: `PageCardButton` minimum height reduced from `64pt` to `44pt` with tight `4pt/2pt` insets and `2pt` image padding.
- **Typography**: Page index and title formatted with `9.5pt` font (semibold for active page, regular for inactive).
- **Rail Width**: Compacted from `80pt` to `72pt`, restoring additional edge-to-edge drawing canvas.
- **DOCS Button**: Compacted to `26pt` height with `9.5pt` bold font.

---

## 2. Dynamic Subtool Menus (`brushSubToolBar` & `bucketSubToolBar`)

- **New Brush Subtool Bar**:
  - Live **Size** slider (1.0 to 40.0 pt).
  - Live **Opacity** slider (5% to 100%).
  - Live **Hardness** slider (0% to 100%).
  - Instant synchronization with `canvas.engineBridge` and persistence to `UserDefaults`.
- **Dynamic Leading Placement**:
  - Pinned top-left under `undoRedoChip`.
  - When `pagesRail` is opened: leading constraint anchors to `pagesRail.trailingAnchor + 12`.
  - When `pagesRail` is closed: leading constraint anchors to `toolRail.trailingAnchor + 12`.
  - Smooth 0.22s ease-out animation when toggling pages.
- **Contextual Visibility**:
  - Displays `brushSubToolBar` when Brush is active.
  - Displays `bucketSubToolBar` when Bucket is active.
  - Hides subtool menus when other tools are selected.

---

## 3. Popover Color Selector

- `ColorPickerViewController` is presented with `modalPresentationStyle = .popover`.
- Anchored to `colorSwatchButton` on the tool rail with `.left` and `.up` arrow directions.
- Direct non-modal popup interaction: click swatch -> opens immediately next to the button -> pick color -> tap outside to dismiss.

---

## 4. Built-in In-App Menu Window (`AppMenuWindowView`)

- **Paper Window Architecture**:
  - Replaced system `UIAlertController` action sheet with native `AppMenuWindowView`.
  - 270x345pt fixed dimensions: **zero scrolling required**.
  - Styled in `DraftingTheme.paperDeep` with `1.5pt` rule border, 14pt rounded corners, and soft drop shadow.
- **Menu Actions**:
  - Notebooks Gallery
  - Rename Document
  - Export & Share... (smooth in-window transition to PNG, PDF, and .drafttable options)
  - Import Photo...
  - Drawing Settings...
  - Reset Canvas View
  - Clear Document
- **Presentation**:
  - Smooth spring scale/fade animation near top-left menu trigger button.
  - Transparent dismiss overlay for outside-tap dismissal.
  - Tactile haptic feedback on presentation and selection.
