# 2026-09-03 — v0.9.2 prerelease: Apple Pencil Pro & Full Drafting Table Feature Parity

## Overview

Version **0.9.2** (build **14**) delivers the complete Apple Pencil Pro feature set alongside full upstream Drafting Table feature parity, addressing the user directive to implement all core feature sets and Pencil Pro functionality and revise as `0.9.x` prior to the `1.0` release.

---

## 1. Apple Pencil Pro & Input Features

### A. Non-Mutating Sibling Hover Overlay (`HoverOverlayView.swift`)
- **Metal Layer Crash Invariant Preserved**: Direct layer mutation on `CanvasView.layer` (`CAMetalLayer`) was identified in v0.7.0 as a heap corruption/crash vector. `HoverOverlayView` is introduced as a transparent sibling `UIView` pinned directly over `CanvasView` in `DraftingTableViewController`.
- **Dynamic Outer Ring**: Scaled precisely to current brush diameter and canvas zoom level (`diameter = min(max(brushSize * canvasScale, 3), 240)`).
- **Active Color & Tool Indication**: Live brush color preview; dashed crimson indicator when Eraser is active.
- **Altitude & Azimuth Tilt Needle**: Visualizes Pencil orientation and approach direction relative to the screen plane.
- **Barrel Roll Tick Indicator**: Renders dynamic roll angle tick on the hover perimeter using Apple Pencil Pro barrel roll (`gesture.rollAngle`).
- **Snapping Target Reticle**: Renders high-contrast diamond snap target when approaching grid intersections.

### B. Apple Pencil Pro Squeeze & Quick Actions
- Squeeze gesture (`UIPencilInteraction.Squeeze`) triggers haptic feedback and displays a contextual floating tool switcher right at the pencil tip's hover coordinate.
- Provides immediate one-touch switching between Brush, Eraser, Shade, Line, Rectangle, Circle, Marquee Select, Lasso Select, Color Picker, and Undo.

### C. Haptic Feedback Service (`HapticFeedbackService.swift`)
- Integrates `UIImpactFeedbackGenerator`, `UISelectionFeedbackGenerator`, and `UINotificationFeedbackGenerator`.
- Discrete tactile feedback for:
  - **Snap Lock**: Light crisp impact when angle or grid snap engages.
  - **Pencil Pro Squeeze**: Medium impact on squeeze began.
  - **Tool Switching**: Selection tick when changing tools via rail, tap, or squeeze.
  - **Undo / Redo / Delete**: Soft impact on stroke state modifications.
  - **Duplicate / Save Success**: Success notification haptic.

### D. 15-Degree Angle Snapping
- Implemented in `CanvasView.makeSample` for vector shape drawing (`Line`, `Rectangle`, `Ellipse`, `Circle`).
- Snaps vector angles to 15-degree steps (`π / 12`) when `angleSnapEnabled` is active.
- Emits a light snap haptic whenever crossing an angle boundary threshold.
- Toggled via the bottom status bar chip `angle: on / off`.

## 2. Upstream Drafting Table Feature Parity

### A. Shade Tool (`DTTool::Shade = 6`)
- Added to C++ core engine (`DTEngine.hpp`, `DTEngine.cpp`), Objective-C++ bridge (`DTEngineBridge.h`, `DTEngineBridge.mm`), and tool rail.
- **Metal Renderer Triangulation**: Implemented ear-clipping triangulation in `DTMetalRenderer.mm` to rasterize closed polygon fills alongside antialiased perimeter strokes with implicit closing chords.
- **Vector PDF & PNG Export**: Fully integrated in `DocumentExportService.swift` with filled path and border stroke rendering.

### B. Stroke Selection & Transformation (`Select` & `Lasso`)
- **Engine Mutations**:
  - `moveStrokes(indices, dx, dy)`: Translates stroke vertices by delta offsets.
  - `duplicateStrokes(indices, dx, dy)`: Clones strokes with offset.
  - `deleteStrokes(indices)`: Removes selected strokes from active layer.
  - `activeLayerStrokeCount()`: Returns stroke count for active layer.
- **Interactive Marquee & Lasso**:
  - Dragging bounding box marquee or lasso boundary highlights selected strokes.
  - Selection bounding box overlay rendered on `HoverOverlayView`.
  - Dragging within the selection bounding box moves strokes in real-time.
- **Selection Action Bar HUD**:
  - Appears automatically when strokes are selected with `Duplicate`, `Delete`, and `Done` action buttons.

### C. Pixel Grid (`px: on / off`)
- Implemented in `DTMetalRenderer.mm`.
- Toggled via the bottom status bar chip `px: on / off`.
- Dynamically activates at high zoom levels (`canvasScale >= 3.5x`), rendering fine 1-document-pixel grid lines for technical drawing alignment.

### D. Document Management
- **Document Title & Rename**:
  - Tap gesture on bottom status bar `statusDocLabel` opens document rename prompt.
  - Also accessible via the navigation ellipsis document menu.
- **Clear Entire Document**:
  - Added destructive confirmation action to clear all pages and strokes.
