# Drafting Table 0.11.0 UI parity test release

This test release changes the product target from a simplified iPad preview to
direct visual and interaction parity with bgkatz's upstream Concept A v4 UI.
The current Metal tile renderer, package persistence, undo transactions, and
Apple Pencil input remain underneath the new shell.

## What changed

- Exact upstream colors, dimensions, 32-color palette, and component geometry.
- Converted upstream Android vector icons instead of SF Symbol substitutes.
- Bundled JetBrains Mono and Inter.
- Original fixed shell: 56pt tool rail, 84pt page deck, 180pt inspector, 28pt
  status bar, full-size canvas behind the overlay panels.
- Original tool ordering and section labels.
- Original page cards, layer rows, layer opacity, BRUSH panel, COLOR panel,
  floating undo/redo chip, menu, settings, and HSV picker language.
- Original active sienna outline and warm paper/ink surfaces; no card shadows,
  large iOS radii, or labeled tool buttons.
- Adaptive collapse preserves the original components instead of reflowing or
  reskinning them.

## Functional in this test build

- Brush and destination-out eraser.
- Undo and redo.
- Two raster layers: select, visibility, and opacity.
- Brush size, opacity, hardness, and color.
- Grid, pixel grid, brush preview, prediction, reset view.
- Package autosave/reopen and Files package opening.
- Apple Pencil coalesced/predicted input, hover, double tap, squeeze, and roll
  plumbing supported by the connected device.

## Present but intentionally unavailable

Bucket, Shade, vector primitives, selection tools, snapping/angle constraints,
uniform alpha, pressure saturation, structural page/layer mutations, image
import, and PNG/PDF export retain their upstream positions but use disabled
ink. Tapping one reports `Not available in this preview`; it never silently
selects Brush.

## What to test on iPad

1. Compare landscape layout directly with `tools/drafting_table.png`: column
   order, widths, status order, icon order, paper colors, active outlines.
2. Rotate to portrait and use split view. Confirm collapsed sections reopen
   from the original Pages/Layers/Color rail icons without moving or resizing
   the Metal canvas.
3. Check that every label remains one line and that status content scrolls
   horizontally rather than wrapping.
4. Draw and erase on both raster layers; change upper-layer opacity and confirm
   the lower layer remains visible.
5. Undo/redo several strokes and relaunch to confirm the same pixels reopen.
6. Exercise brush size/alpha/hardness, the 32 palette colors, full HSV picker,
   recents, and user slots.
7. Exercise Pencil hover, double tap, squeeze palette, predicted tail, pan,
   pinch, and rotation. Report latency, seam, or commit-flash observations.
8. Tap disabled controls and confirm they never change the active Brush/Eraser.

This is a design-parity test release, not full upstream feature parity yet.
