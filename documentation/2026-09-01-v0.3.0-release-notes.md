# 2026-09-01 — Drafting Table v0.3.0 release notes

Pencil curve-quality and device-tuning iteration.

## New in this build

- Round joins are rendered at every real/predicted Pencil sample, closing gaps on tight curves and repeated points;
- Real graphite is uniform opaque ink, preventing overlapping curve triangles from creating dark spots;
- Predicted tails retain a lighter 30% preview and use the same graphite hue;
- Persistent `Pen activation` slider from 0–20%;
- Pencil contact begins only after normalized force crosses the selected activation threshold;
- Lift-off uses a lower 55% hysteresis threshold to prevent pressure noise from fragmenting a stroke;
- Below-threshold contact and final low-force lift samples are excluded from the committed stroke;
- Direct finger drawing behavior remains unchanged.

The activation control is a software pressure threshold intended for light-contact/screen-protector tuning. UIKit does not allow an app to change Apple Pencil's physical hover or hardware detection height.

## Still not implemented

- Persistent documents/pages/layers;
- Eraser, shade, vector tools, snapping, selection, pan/zoom, and export;
- Connection of the sparse Metal tile backend to the visible immediate renderer.

`DraftingTable.ipa` is an unsigned arm64 device build intended for SideStore or another sideloading signer.
