# Drafting Table v0.7.1 — launch crash hotfix

Released 2026-09-02 from source commit `83ae57b`.

## User report

Version 0.7.0 showed the beige paper background and then exited during launch.
The beige frame proved UIKit/scene creation had begun; it did not prove the
Metal renderer or workspace layout had completed.

## Reproduction and diagnosis

The new simulator gate reproduced a real v0.7 abort on a clean install. Run
`33603527090` recorded allocator heap corruption at 07:30:58.803 UTC followed
by `SIGABRT`. This ruled out SideStore and the user's existing autosave as the
only causes.

The most credible v0.7 regression was the expanded per-vertex Metal ABI: an
aligned `float4` plus scalar was added to the C++/Metal vertex and interstage
structures. The crash occurred during first-frame Metal setup. V0.7 also
introduced unbounded retained-snapshot copies, smoothing expansion, geometry
fans, and full-canvas thumbnail PNG generation, all of which could cause a
separate launch OOM with an existing large document.

Several later red simulator runs were harness false negatives caused by console
attachment, transient launch PIDs, or unsupported process queries. They were
not treated as new source crash evidence.

## Fixes

- Restored the previously proven compact Metal vertex layout.
- Moved color/hardness into an explicitly aligned two-`float4` fragment uniform.
- Added nil checks before binding every dynamically allocated Metal buffer.
- Bounded display snapshots to 1,024 points per stroke and 65,536 points total.
- Bounded renderer input/smoothing and reduced repeated cap geometry.
- Replaced full-canvas thumbnail PNG/downscale with direct target-size drawing.
- Added safe UserDefaults conversions for tool/color values.
- Temporarily disabled automatic page thumbnails during layout.
- Temporarily disabled the hover CAShapeLayer attached to MTKView's Metal layer.
- Preserved Pencil drawing, shape tools, colors, hardness, grid, page/layer
  operations, Files Open/Save Copy, PNG/PDF export, autosave, and archive v3.

## Validation

- Portable engine tests pass, including the new bounded-display snapshot test.
- Xcode device build and unsigned IPA packaging pass.
- Branch run `33691923175` built a normal Release simulator app, installed it
  into a clean iPad simulator, launched it without console attachment, waited,
  and confirmed a live `DraftingTable` process.
- Packaged IPA: version `0.7.1`, build `9`, arm64, compiled assets and Metal
  library present.
