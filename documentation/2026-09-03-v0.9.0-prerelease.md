# 2026-09-03 — v0.9.0 prerelease (0.9.x stabilization line)

The 0.9.x line stays open until a stable full-port release. 0.9.0 starts it
with the original app's look plus three user-facing fixes/features.

## Pen-sample dots removed

Curved brush lines showed beading along their length. Cause: the renderer
fanned a round cap at every 4th interpolated point (plus a larger fringe
pass), so each fan read as a dot where pressure varied. Dense smoothed
quads already overlap along the body, so intermediate fans are gone;
single taps still render as dots and every stroke keeps its end caps.
File: `platforms/ipad/Bridge/DTMetalRenderer.mm`.

## Color picker dialog

New `platforms/ipad/ColorPickerViewController.swift`, mirroring the
original picker: HSV square plus hue slider, HEX field plus RGB readout,
current/previous swatches, the upstream 32-cell drafting palette, an
8-color LRU recents row, and 4 long-press user slots (recents/slots in
UserDefaults). Reached from Settings under Brush color; live-picks drive
the existing brush-color path. Eyedropper is staged: it reports that the
tile sampler (M2) is still pending. Picker colors are opaque, matching the
original; brush opacity stays a separate slider.

## Page thumbnails, background cached

The v0.7.1 hotfix blanked thumbnails because they rasterized synchronously
in layout. They are back through an isolated cache: the rail callback only
returns cached art (or nil) and schedules a utility-queue render of a
96x60 target; an epoch counter orphans in-flight renders across document
mutations so stale art can never land. No snapshot or raster work runs on
the main thread.

## Still engine-blocked (unchanged targets)

Bucket/shade (tile backend M2), selection and transforms (M6), snapping
(M5), pixel grid (tile compositor M11), multi-document browser and image
import (M7/M8). Rail buttons for those announce their milestone.

## Validation

- Portable core tests green (circle round-trip included).
- Simulator launch gate green with ASan still enabled.
- Release: v0.9.0 prerelease IPA, version 0.9.0 build 12.
