# 2026-09-04 — v0.9.9 Release: Stroke Input Freeze Fix, Layer Drag-to-Reorder, Vector Badges & Custom Color Slots

## Overview

Version **0.9.9** (build **18**) delivers:
1. **Critical Fix for Stroke Input Limit Lockup**: Eliminated the canvas input freeze bug after prolonged drawing sessions by un-gating active in-progress strokes in the engine snapshot, expanding bridge point limits to 2,000,000, raising Metal vertex budget to 5,000,000, wrapping the draw pass in `@autoreleasepool`, and adding defensive touch phase reset.
2. **32-Cell Curated Palette & Custom Color Slots (`mySlots`)**: Added a 2×2 grid of user color slots directly on the tool rail with tap-to-select and long-press-to-pin, plus popover auto-sizing to 360×580pt for zero-scroll 32-cell palette display.
3. **Interactive Direct Touch Layer Drag-to-Reorder**: Added a dedicated drag handle and pan gesture recognizer to layer rows with real-time visual spring translation, elevation drop shadow, haptics, and native engine layer reordering on release.
4. **Explicit Vector vs Raster Layer Creation & Badging**: Added dedicated `+` (Raster) and `+V` (Vector) buttons to the layer rail header and high-contrast `[R]` and `[V]` pill badges to each layer row.
5. **Left-Anchored Layer Rail & Concept A Alignment**: Shifted the layer rail to the left side stacked beside the page rail, compacting it to 120pt to maximize edge-to-edge drawing canvas.

---

## 1. Stroke Limit Input Lockup Fix

- **DTEngine Snapshot Guarantee**: `DTEngine::snapshotForDisplay` previously gated `activeStroke_` on accumulated point count. Active in-progress strokes are now unconditionally included so drawing strokes never disappear or fail to register during continuous use.
- **Bridge Point Ceiling**: Increased point decimation threshold in `DTEngineBridge.mm` from 65,536 points (~100 normal pencil strokes) to 2,000,000 points with 4,096 points per stroke.
- **Metal Vertex Budget**: Raised per-frame vertex ceiling in `DTMetalRenderer.mm` from 220,000 to 5,000,000 vertices and ensured the active stroke is never dropped even under heavy vertex loads.
- **Memory & Touch Resilience**: Wrapped `drawInMTKView:` in `@autoreleasepool { ... }` to prevent temporary vertex buffer and `NSValue` allocations from accumulating; added touch phase reset in `CanvasView.touchesBegan` to prevent orphaned touch lockups.

## 2. 32-Cell Palette & Custom Slots (`mySlots`)

- **Rail Color Slots**:
  - 4 circular user-assignable color buttons positioned directly under the primary color swatch.
  - **Tap**: Instantly selects the slot color, sets active brush color, and emits haptic feedback. If empty, saves current color.
  - **Long-Press**: Pins current active color to the slot, stores in `UserDefaults` (`draftingTable.colorSlots`), and shows a confirmation toast.
- **Popover Sizing & Sync**:
  - Resized `ColorPickerViewController` popover to `360 × 580 pt` with 6pt grid spacing, eliminating horizontal clipping.
  - Added `onDismiss` notification to synchronize any palette/slot changes made inside the picker dialog back to the tool rail slots immediately.

---

## 3. Layer Drag-to-Reorder

- **Gesture Interaction**: Pan gesture on each layer row's `line.3.horizontal` drag handle activates vertical reordering.
- **Live Visual Feedback**: Neighboring rows dynamically translate up/down with spring physics as the dragged row passes their midpoints.
- **Commit**: On gesture release, calls `engineBridge.moveLayer(from:to:)` and syncs layer indices cleanly.

---

## 4. Vector vs Raster Badging & Layer Controls

- **Dual Add Buttons**:
  - `+` button creates a standard raster drawing layer ("Raster N").
  - `+V` button creates a dedicated vector shape layer ("Vector N").
- **Row Badges**:
  - `[R]` pill badge for raster layers (warm ink soft).
  - `[V]` pill badge for vector layers (vibrant blue accent).
