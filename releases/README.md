# IPA releases

IPA binaries are attached to GitHub Releases rather than committed to Git.

- Latest release: <https://github.com/Code-Andy/drafting_table/releases/latest>
- All releases: <https://github.com/Code-Andy/drafting_table/releases>
- CI runs: <https://github.com/Code-Andy/drafting_table/actions/workflows/ipad-build.yml>

Each release asset named `DraftingTable.ipa` is an unsigned device build. Sign
and install it with SideStore or another sideloading tool. Release notes state
which product features are actually usable in that build.
